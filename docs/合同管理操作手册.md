# 合同管理操作手册

## 一、合同入库流程

合同数据来源于文档处理流水线，支持两种入库方式：

### 1.1 飞书文件夹自动入库

配置飞书文件夹监听后，系统自动扫描并处理新增的 PDF 文档：

1. 系统将文档上传并触发 OCR 解析
2. 提取完成后进入 **待审核** 状态（若监听配置了自动审批则自动跳过）
3. 审核通过后自动执行 **切片 + 向量化**：
   - 提取合同元信息（甲方、乙方、合同类型、签订日期、到期日期、金额）
   - 按滑动窗口分析条款结构，识别条款层级
   - 生成合同概要（200~400 字，作为第 0 条入库）
   - 创建合同记录 + 条款树

### 1.2 手动上传

通过文档管理页面上传 PDF 文件，审批流程同上。

## 二、合同列表页

### 2.1 查看合同

进入合同列表页，支持以下筛选条件：

| 筛选项 | 说明 |
|--------|------|
| 关键词 | 模糊匹配合同名称/项目名 |
| 甲方名称 | 按甲方主体筛选 |
| 乙方名称 | 按乙方主体筛选 |
| 合同类型 | 下拉选择类型 |

表格显示：合同名称、甲方、乙方、合同类型、签订日期、到期日期、金额、条款数。

**到期日期标识**：
- 距到期 < 30 天：黄色警告
- 已过期：红色标识

### 2.2 编辑合同

点击 **编辑** 按钮，可修改：
- 合同类型、项目名称
- 甲方、乙方
- 签订日期、生效日期、到期日期
- 合同金额
- 合同摘要

### 2.3 删除合同

- **单条删除**：点击删除按钮，二次确认后执行。同时级联删除条款、文档记录和审查报告。
- **批量删除**：勾选多条后点击批量删除。

### 2.4 触发审查

点击 **审查** 按钮 → 系统创建审查任务 → 定时任务异步执行 → 完成后生成审查报告并写入飞书文档。

已有审查记录时，按钮变为 **审查结果**，点击直接跳转查看飞书文档中的报告。

### 2.5 跳转文档

合同名称旁若显示外链图标，点击可跳转到原始飞书文档。

## 三、合同详情页

### 3.1 基本信息

顶部卡片展示合同完整信息：项目名称、合同类型、甲方、乙方、签订/生效/到期日期、金额、条款数、合同摘要。

### 3.2 条款树浏览

页面左右分栏：

- **左侧**：条款树，可折叠展开各级条款
- **右侧**：选中条款的详情面板
  - 条款标题（完整路径，如"合作范围-服务内容-软件开发"）
  - 条款原文（Markdown 渲染）
  - 条款摘要（灰色背景，自动生成）

### 3.3 编辑条款

点击条款详情中的 **编辑** 按钮：
- 弹出 textarea 编辑框
- 保存后系统标记为待处理状态，后台异步重新生成摘要并同步向量库

### 3.4 新增条款

点击 **新增** 按钮：
- 填写条款标题和内容
- 系统自动分配序号
- 同样异步生成摘要和向量

### 3.5 删除条款

点击 **删除** 按钮：
- 级联删除所有子孙条款
- 立即清理向量库中对应的 chunks
- 后台异步更新合同摘要

### 3.6 查看相似合同

详情页底部展示相似合同列表，匹配逻辑：相同合同类型 + 相同签约主体。

## 四、合同审查

### 4.1 触发审查

在合同列表中点击 **审查** → 后台创建审查任务。

### 4.2 审查执行（自动）

定时任务每轮最多处理 5 条待审查记录：

1. 获取合同条款树
2. 对每个条款并行调用审查 Agent（并发上限 2）
3. 审查 Agent 具备跨条款引用查询能力（如合同中提到"按第七条执行"，Agent 会自动查询被引用条款）
4. 汇总所有条款的审查结果，生成 Markdown 报告

每条审查结果包含：
- **风险等级**：🔴 高风险 / 🟡 中风险 / 🟢 低风险
- **法律意见**：基于条款原文的法律风险分析
- **修改建议**：具体的修改建议

### 4.3 查看结果

审查完成后：
- 报告自动写入飞书云文档
- 在合同列表中点击 **审查结果** 查看
- 也可通过飞书 Bot 消息中的链接直接跳转

## 五、合同 Agent 对话

在飞书 Bot 或 Web 对话中，合同 Agent 提供以下能力：

| 能力 | 说明 | 示例提问 |
|------|------|----------|
| 搜索合同 | 按关键词/甲乙方/类型搜索 | "找一下图星科技作为甲方的合同" |
| 合同统计 | 总数/按类型/按甲方/即将到期 | "目前有多少份服务类合同？" |
| 搜索条款 | 在指定合同内搜索条款 | "合同 207 里有没有关于付款的条款？" |
| 条款摘要对比 | 跨合同对比同类条款摘要 | "对比两份合同的保密条款" |
| 条款全文对比 | 跨合同对比条款原文差异 | "这两份合同的违约责任条款原文有什么区别？" |
| 查找相似合同 | 按类型+签约主体查找 | "有没有和京东直播协议类似的合同？" |

**不支持的操作**（Agent 只读不写）：
- 不能修改、创建、删除合同或条款
- 不能触发合同审查（审查需通过列表页按钮触发）

## 六、合同类型管理

管理合同类型字典，影响 LLM 元信息提取时的类型匹配：

| 操作 | 说明 |
|------|------|
| 新增 | 输入类型名称和编码（如"采购"/"purchase"） |
| 编辑 | 修改名称或编码 |
| 启用/禁用 | 禁用的类型不参与 LLM 自动匹配 |
| 删除 | 软删除，不可恢复 |

---

## 七、定时任务说明

以下定时任务与合同管理相关，系统自动运行，无需手动操作：

| 任务 | 频率 | 说明 |
|------|------|------|
| 条款摘要处理 | 每轮调度 | 为新条款生成摘要、合并更新合同摘要、同步向量库 |
| 合同风险审查 | 每轮调度 | 处理待审查记录，生成报告并推送飞书 |
| 合同到期提醒 | 每轮调度 | 检查 30/7/1 天到期的合同并记录日志 |
| 临时合同清理 | 每轮调度 | 删除创建超过 7 天的临时审查合同 |

## 八、常见问题

**Q：文档审批通过后，合同没有立即出现？**

A：审批后需经历切片（多次 LLM 调用）→ 创建合同，属于异步流程。补偿任务每轮调度处理 1 个文档，若队列较长需等待。

**Q：条款摘要显示"生成中"？**

A：条款增删改后，摘要由定时任务异步生成，通常几分钟内完成。

**Q：审查报告什么时候能出？**

A：点击审查后创建 pending 任务，定时任务异步执行。一份合同的审查耗时取决于条款数量（每个条款独立 Agent 调用）。

**Q：合同 Agent 搜不到结果？**

A：Agent 只查询已入库的合同数据。文档尚在提取/审核中时不会出现在搜索结果中。
