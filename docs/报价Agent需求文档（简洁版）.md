## 报价 Agent — 产品需求文档

版本 v1.0 | 2026-06-10

---

## 一、背景

公司报价体系成熟但知识高度集中在资深业务员手中，新员工和新业务员无法快速了解已有报价规则，导致响应慢、知识流失风险高、变更不可追溯。

---

## 二、产品目标

构建报价规则管理系统和配套 Agent Tool，让任意员工都能快速查询甲方报价并辅助生成报价或回答客户问题。

---

## 三、功能需求

### 3.1 报价规则管理（一期 P0）

**新增报价规则**

支持手动录入和 Excel 报价单解析两种方式。每个甲方对应唯一一套生效报价规则。手动录入时选择甲方后填写一级项目和二级项目（名称、编码、单价、单位、备注、排序）。录入后保存为草稿，提交后进入审批流程。若该甲方已有生效规则，提示用户是否基于当前规则修改。

**Excel 报价单解析**

上传 .xlsx / .xls 格式文件（不超过 20MB），系统自动识别表头并映射到一级项目、二级项目、单价等字段。无法识别的行标记为"待确认"。解析结果以可编辑表格呈现，用户确认无误后提交审批。支持对已有规则重新上传 Excel 解析，审批通过后旧明细全部失效并归档。

**修改报价规则**

可修改一级/二级明细的项目名称、编码、单价、单位、备注和排序，可新增或删除明细项。修改保存后自动生成新版本草稿并触发审批，修改内容在审批通过前不影响当前生效版本。修改页面提供变更对比视图，高亮展示新增、修改和删除的明细。

### 3.2 审批管理（一期 P0）

审批是报价规则生效的唯一入口。新增提交、修改保存、Excel 重新解析提交均触发审批。审批人由系统管理员预设（如报价主管、业务总监）。

审批页面展示完整报价规则内容和变更对比。通过时可填写备注，驳回时必须填写原因。审批通过后新版本立即生效，系统自动将上一生效版本创建完整快照（含所有明细）存入归档，并通知发起人。审批驳回后规则退回草稿状态，修改后可重新提交。

### 3.3 报价查询 — Agent Tool（一期 P0）

Tool 名称：get_quotation_rule

用户通过自然语言描述需求，Agent 自动提取甲方名称，查询最新生效的报价规则并原样返回。

输入参数：client_name（甲方名称或关键词，必填），item_keyword（项目关键词，选填，用于过滤特定明细项）。

返回内容：甲方名称、版本号、生效时间、一级/二级明细树（含名称、编码、单价、单位）。

匹配策略：先精确匹配甲方名称，未命中则模糊匹配返回候选列表供用户确认。无生效规则时提示"该甲方暂无生效报价规则"。Agent 仅返回生效数据，不暴露草稿和归档信息。

### 3.4 版本管理（一期 P1）

审批通过后旧版本自动归档，所有历史版本永久保留可追溯查询。管理后台支持查看任意归档版本的完整快照，支持跨版本 diff 对比。所有写操作记录审计日志（操作人、时间、变更内容）。

### 3.5 报价单管理（二期 P2）

上传真实业务报价单（Excel / PDF），自动解析项目明细并结构化存储，按甲方和时间维度归档形成报价历史数据库。将真实报价单与系统生效规则自动比对，发现偏差时生成预警报告。基于存档数据提供报价频次统计、单价趋势分析和客户维度报表。

---

## 四、数据实体

系统包含五个核心实体。

甲方（Client）：报价规则的归属主体，包含名称、联系人、状态。每个甲方同一时间仅有一套生效报价规则。

报价规则（QuotationRule）：归属于某个甲方的完整报价方案，包含版本号、状态（草稿/待审批/生效/已归档）、来源类型（手动/Excel导入）、创建人、审批人。

报价明细（QuotationItem）：报价规则中的具体项目，支持一级和二级层级结构，包含项目名称、编码、单价、单位、备注、排序号。二级明细通过 parent_id 指向一级。

审批记录（ApprovalRecord）：每次审批的完整流水，包含审批类型、发起人、审批人、状态、意见、提交和完成时间。

版本归档（VersionArchive）：审批通过后旧版本的完整 JSON 快照，包含归档时间、版本号和触发原因，永久保留不可删除。

---

## 五、状态流转

报价规则有四个状态：草稿、待审批、生效、已归档。

手动新增或 Excel 解析后进入草稿状态。提交审批后变为待审批。审批通过后变为生效，同时上一生效版本自动归档。审批驳回后退回草稿。当同一甲方的新版本审批通过时，原生效版本自动归档。

---

## 六、数据生命周期

收集：通过手动录入或 Excel 解析写入，均需审批校验。二期增加真实报价单存档作为数据样本。

存储：每个甲方同一时间仅保留一个生效版本。草稿与生效版本物理隔离。每次版本变更全量快照归档，永久保留。

使用：Agent Tool 仅返回生效数据。管理后台可查看所有状态数据和归档历史。

迭代：业务人员发起修改 → 审批管控 → 版本归档 → 二期数据比对预警推动规则更新，形成闭环。

---

## 七、非功能性需求

权限管控：报价规则的新增/修改/审批需角色权限控制，Agent 查询仅返回生效数据。

数据安全：归档数据不可删除，所有变更操作记录审计日志。

性能：Agent Tool 查询响应不超过 3 秒，Excel 解析（500 行以内）不超过 10 秒。

兼容性：Excel 解析支持 .xlsx 和 .xls，兼容常见表头命名变体。

---

## 八、里程碑

一期 MVP（3-4 周）：报价规则手动新增 + 修改 + 审批 + Agent 查询，交付可运行的管理后台和 Agent Tool。

一期增强（2-3 周）：Excel 解析导入 + 重新解析 + 版本归档追溯，交付完整的一期功能闭环。

二期（4-5 周）：报价单管理 + 数据统计分析，交付报价单存档、数据报表和规则比对预警。
