# 合同管理 Agent 产品文档

## 一、产品概述

合同管理 Agent 是一套覆盖合同**入库 → 存储 → 查询 → 对比 → 生成**全链路的智能管理系统。法务人员通过飞书 Bot 对话或 Web 管理后台，即可完成合同的日常管理工作。

---

## 二、核心功能

### 2.1 功能总览

| 功能 | 说明 | 入口 |
|------|------|------|
| 合同入库 | 上传合同文件，自动提取甲乙方、类型、条款 | Web 后台 / 飞书文件夹自动同步 |
| 合同管理 | 查看/编辑/删除合同，管理甲乙方和合同类型 | Web 后台 |
| 合同查询 | 按甲方、乙方、项目、类型、时间等多维度搜索 | 飞书 Bot / Web 后台 |
| 合同统计 | 按类型、时间、金额等维度统计合同情况 | 飞书 Bot / Web 后台 |
| 条款查询 | 按条款内容语义搜索，支持跨合同同类条款聚合 | 飞书 Bot |
| 合同对比 | 上传合同找相似 / 指定两份合同逐条款对比 | 飞书 Bot / Web 后台 |
| 合同生成 | 基于模板 + 对话上下文自动生成合同到飞书 | 飞书 Bot |
| 到期提醒 | 合同到期前 3 个月起每月提醒，到期前 7 天和当天再提醒 | 飞书 Bot 主动推送 |
| 模板管理 | 管理合同生成模板（通用模板型 / 具体条目型） | Web 后台 |

## 三、数据模型

### 3.1 核心表结构

```
┌─────────────────────────────────────────────────────────────────┐
│                        contract_type                             │
│  合同类型字典表（支持动态扩展）                                      │
│  id | name | code | description | is_active                      │
└─────────────────────────────────────────────────────────────────┘
                              ▲
                              │ FK
┌──────────────────────────────┼──────────────────────────────────┐
│                         contract                                 │
│  合同主表（关联 Document 侧表）                                     │
│  id | document_id | contract_type_id | party_a_client_id | ...  │
│     | party_b_client_id | project_name | signing_date | ...     │
│     | effective_date | expiry_date | total_amount | summary     │
└──────────────────────────────┬──────────────────────────────────┘
                               │ 1:N
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│                       contract_clause                            │
│  合同条款表（单表父子结构）                                          │
│  id | contract_id | parent_id | clause_index | clause_title     │
│     | clause_level | original_text | summary | sort_order       │
│                                                                  │
│  parent_id: null=顶级条款, 非null=子条款                            │
│  clause_index: 0=合同概要, 1+=实际条款                              │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 与现有系统的关系

```
quotation_client (甲方/乙方)           document (通用文档)
      │                                    │
      │ party_a_client_id                   │ document_id (1:1)
      │ party_b_client_id                   │
      ▼                                    ▼
┌─────────────────────────────────────────────────┐
│                   contract                        │
│  复用甲方数据，关联文档流水线                       │
└─────────────────────────────────────────────────┘
```

**设计要点**：
- Contract 不替代 Document，而是作为侧表扩展
- 甲方/乙方复用 `quotation_client` 表，扩展了社会信用代码等字段
- 合同类型使用独立字典表，支持 LLM 自动发现新类型并动态扩展

## 四、合同入库流程

### 4.1 两种入库方式

```
方式一：Web 手动上传
  用户 → 进入合同管理页面 → 上传文件 → 系统自动处理 → 人工审核 → 正式入库
  （在合同管理页面上传的文件即视为合同，无需选择类型）

方式二：飞书文件夹自动同步
  用户 → 将合同放入飞书监听文件夹 → 系统定时扫描 → 自动处理 → 入库
```

### 4.2 自动处理流程

```
上传合同文件
    │
    ▼
┌──────────────┐
│ 文档提取       │  ← 文件转 Markdown，按页存储
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 人工审核       │  ← 审核员核对提取内容，可修正
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 条款切片       │  ← LLM 分析合同结构，拆分为独立条款
│  ├─ 元信息提取  │     提取甲方、乙方、合同类型
│  ├─ 结构分析    │     滑动窗口识别条款边界
│  ├─ 明细摘要化  │     大段表格/清单替换为摘要
│  └─ 概要生成    │     生成合同概要（第 0 条）
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 转 Contract   │  ← 写入 Contract + ContractClause 表
│ + 合同类型匹配  │     自动匹配/创建合同类型
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 向量化入库     │  ← 条款摘要向量化，存入 PGVector
└──────────────┘
```

### 4.3 合同类型自动匹配

```
LLM 提取合同类型字符串（如："技术开发"）
    │
    ├── 精确匹配 ContractType 表 → 找到 → 直接使用
    │
    ├── 未找到 → 模糊匹配（名称相似度）→ 有相似 → 使用最相似类型
    │
    └── 无相似 → 自动创建新类型 → 记录日志 → 管理员可审核
```

## 五、查询与检索架构

### 5.1 双层检索体系

```
用户提问
    │
    ├── "查文件"类问题（找合同）
    │   └── contract_summary_search
    │       对合同摘要向量做语义检索
    │       返回：匹配的合同列表 + 摘要
    │
    ├── "查条款"类问题（问法律意见）
    │   └── contract_clause_search
    │       对条款摘要向量做语义检索
    │       返回：匹配的条款原文 + 出处
    │
    ├── "查数"类问题（统计）
    │   └── contract_search / contract_stats
    │       SQL 结构化查询
    │       返回：数量、金额、分布
    │
    └── "对比"类问题
        └── compare_clause_summaries / compare_clause_fulltext
            先摘要对比（低成本），必要时升级原文对比
            返回：逐条款差异报告
```

### 5.2 Agent 工具调用链

```
用户: "对比一下合同A和合同B的违约责任条款"
    │
    ▼
Agent 判断意图 → "对比" → 选 compare_clause_summaries
    │
    ▼
工具执行: 读取 ContractClause 表 → 取两份合同的"违约责任"条款
    │
    ▼
LLM 对比两份条款摘要 → 输出差异
    │
    ▼
Agent 判断摘要对比是否足够回答用户问题
    │
    ├── 足够 → 直接返回对比结果
    └── 不足（如需要具体数字）→ 自动升级调 compare_clause_fulltext
```

## 六、合同对比流程

### 6.1 场景一：上传合同找相似

```
用户: 上传合同文件 + "找一下和这个合同类似的，对比下差异"
    │
    ▼
┌──────────────────┐
│ 临时处理通道       │  ← 不进入入库流程，内存处理
│ 提取 → 切片 → 得条款│     用完即焚，不写数据库
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ 逐条款向量检索     │  ← 用每条核心条款的 summary 搜向量库
│ 找相似合同         │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ 汇总排序          │  ← 按命中条款数排序，返回 Top 3
│ 返回给用户确认     │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ 用户选择对比合同   │  ← 确认要对比的目标合同
│ 逐条款对比        │     摘要对比 → 必要时原文对比
│ 输出对比报告      │
└──────────────────┘
```

### 6.2 场景二：指定两份合同对比

```
用户: "对比合同A和合同B的付款条款"
    │
    ▼
Agent 调 contract_search → 找到合同A和合同B
    │
    ▼
Agent 调 compare_clause_summaries(contract_id_a, contract_id_b, "付款")
    │
    ▼
返回结构化对比报告
```

## 七、使用示例

### 7.1 查文件

| 用户提问 | 系统行为 |
|---------|---------|
| "我们和A公司签过哪些合同？" | 结构化搜索 party_a=A公司，返回合同列表 |
| "有没有关于智慧城市项目的合同？" | 按 project_name 搜索 |
| "今年签了多少份采购合同？" | 按 contract_type+时间 统计 |
| "列出最近一年所有的技术服务合同" | 按类型+时间范围搜索，返回列表 |

### 7.2 查条款

| 用户提问 | 系统行为 |
|---------|---------|
| "我们合同里关于保密期限的条款都怎么写的？" | 向量检索"保密期限"，跨合同返回所有相关条款 |
| "违约责任一般怎么约定违约金比例？" | 向量检索"违约金"，返回各合同的违约金条款 |
| "争议解决条款里选了哪些仲裁机构？" | 向量检索"争议解决"，提取仲裁机构信息 |
| "和A公司那份采购合同付款条件是什么？" | 先定位合同，再检索"付款"条款 |

### 7.3 查数

| 用户提问 | 系统行为 |
|---------|---------|
| "我们一共有多少份合同？" | 统计合同总数 |
| "今年签的合同总金额是多少？" | 按时间聚合 total_amount |
| "按合同类型分一下，各有多少份？" | 按 contract_type 分组统计 |
| "下个月有哪些合同要到期？" | 按 expiry_date 范围查询 |

### 7.4 对比

| 用户提问 | 系统行为 |
|---------|---------|
| "对比合同A和合同B的违约责任条款" | 摘要对比 → 输出差异 |
| "合同A和合同B的付款方式有什么不同？" | 原文对比 → 逐条差异 |
| [上传合同] "找一下类似的合同，对比下差异" | 临时处理 → 向量检索 → 汇总 → 对比 |
| "所有合同里违约金比例最高的是哪份？" | 跨合同检索"违约金" → 提取比例 → 排序 |

### 7.5 生成

| 用户提问 | 系统行为 |
|---------|---------|
| "帮我生成一份技术服务合同，甲方是A公司" | 匹配模板 → 填充占位符 → 生成到飞书 |
| "基于刚才讨论的内容，生成一份采购合同" | 从对话上下文提取信息 → 填充模板 → 生成 |

## 八、功能边界

### 飞书 Bot 负责（对话式，即时响应）

- 合同查询、条款查询、合同统计
- 合同对比、合同生成
- 到期提醒主动推送

### Web 管理后台负责（需要可视化操作）

- 合同上传、合同审核
- 合同列表/详情查看、条款树编辑
- 模板管理、甲方管理
- 合同类型管理、统计面板

---

## 九、本期不包含的能力

- 合同条款的合规性审查与风险打分
- 多份合同差异的可视化并排比对界面
- 电子签章对接
- 合同履行进度跟踪
- 合同审批流程定制
